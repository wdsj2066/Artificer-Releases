# Artificer

此仓库仅用于分发 Artificer 官方安装包与自动更新文件，源码仓库保持私密。

## 下载

请到 [Releases](https://github.com/wdsj2066/Artificer-Releases/releases) 下载最新版本的 Windows 安装程序。

## 自动更新

采用此更新源的版本可在应用内检查、下载更新，并在确认后重启安装。
旧版本使用私密仓库作为更新源，需要手动安装一次采用公开更新源的新版本。

发布附件包括安装程序（`.exe`）、差分更新信息（`.exe.blockmap`）及版本描述（`latest.yml`）。请勿单独删除更新元数据。

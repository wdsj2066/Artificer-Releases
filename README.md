# Artificer / AI 工作平台

一个面向个人与团队的 AI 工作平台，让智能体在真实工作区中理解任务、制定计划、调用工具并交付结果。支持代码、文件、终端、文档和多渠道协作，同时保留丰富的扩展能力。

## 下载与更新

请到 [Releases](https://github.com/wdsj2066/Artificer-Releases/releases) 下载最新 Windows 安装包。采用公开更新源的版本可在应用内检查更新、下载并确认重启安装；早期使用私密更新源的版本需要先手动安装一次新版。
